# Study forms and instruments

**Nothing here has been used. No study has been run. No participant exists.**

These are the paper materials for the classroom evaluation described in
`docs/RESEARCH_PLAN.md` and `docs/STUDY_PROTOCOL.md`. Every one is a **draft**
that must be reviewed and edited by the team and by the relevant ethics
committee before it is printed, handed to anyone, or submitted anywhere.

| File | Who receives it | Language |
| --- | --- | --- |
| `S1_information_parent_TH.md` | parent/guardian, before consent | Thai + English |
| `S2_consent_parent_TH.md` | parent/guardian, signed | Thai + English |
| `S3_assent_student_TH.md` | the student, read aloud for primary levels | Thai + English |
| `Q1_questionnaire_TH.md` | the student, immediately after play | Thai + English |
| `S4_data_record_TH.md` | the teacher, one row per student | Thai + English |

Everything is bilingual in one file: the Thai is what a student or parent reads,
and the English sits underneath so a reviewer who does not read Thai can still
check the wording — and so that a reader can confirm the two versions say the
same thing.

## Blanks

Bracketed fields `[ ]` are for the team to complete: names, phone numbers,
school, dates, the retention period. None of them are filled in here, on purpose.
No name or contact detail in this project was invented.

## Before anything is printed

- [ ] An ethics committee has reviewed this material, in writing, **before** the
      first session
- [ ] The school director has approved the sessions in writing
- [ ] The Thai and the English have been checked against each other by someone
      who reads both
- [ ] The reading level of `S3` matches the youngest participating class
- [ ] Every `[ ]` has been filled in, or removed
- [ ] The draft banners at the top of each file have been deleted

## The one thing to get right

The forms exist so that a student's decision means something. That means:

- a student who does **not** sign `S3` gets the ordinary lesson, and nothing about
  their day is different;
- nobody is asked twice, and nobody is asked in front of the class;
- the case code on `S4` is a label, not an identity — never a name, an email, a
  student number or a birthdate;
- the paper that links a code to a person is the sensitive document, and it is
  destroyed **first**.

`docs/STUDY_PROTOCOL.md` §6 explains why the code filter is a real protection
for *format* and not a substitute for a teacher's judgement.
