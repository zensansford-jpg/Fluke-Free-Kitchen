### หมายเหตุสำหรับทีมงาน / Note for the team

- **ห้ามเขียนชื่อ** กำกับด้วยรหัสเท่านั้น / **Do not write a name.** Use the case code only.
- เก็บทันทีเมื่อทำเสร็จ เพื่อไม่ให้เพื่อน ๆ เห็นคำตอบ / Collect immediately, so neighbours cannot copy.
- ข้อ 7–12 เป็น **ความตั้งใจที่นักเรียนรายงานเอง** ห้ามสรุปว่าเป็นพฤติกรรมที่เกิดขึ้นจริง
  Items 7–12 are **self-reported intentions**. Never present them as observed behaviour.
- ผลส่วนนี้รายงานเป็น **จำนวนและร้อยละของแต่ละตัวเลือก** ไม่ใช่ค่าเฉลี่ยรวมของทุกข้อ
  Report counts and percentages per option, not a single average across items.
- ข้อ 13–14 เป็นคำถามปลายเปิด ให้ยกคำตอบที่เป็นตัวแทน (ไม่ระบุชื่อ) ในรายงาน ไม่ต้องสรุปเป็นตัวเลข
  Items 13–14 are open; quote representative (un-named) answers rather than counting them.
