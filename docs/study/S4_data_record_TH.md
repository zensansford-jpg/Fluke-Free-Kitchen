### หมายเหตุสำหรับทีมงาน / Note for the team

- **หนึ่งเครื่อง หนึ่งคน**: ส่งออกไฟล์ของนักเรียนคนแรกและย้ายออกก่อนที่คนที่สองจะเริ่ม มิฉะนั้นข้อมูลคนแรกจะถูกเขียนทับ
  **One device, one student:** export and move the first student's file before the next one starts,
  or the second student's save overwrites the first student's data. This is the main way a session's
  data gets lost.
- กรอกแถวสรุป **ทันทีในวันนั้น** ขณะที่ยังจำได้ว่าใครขาด
  Fill in the summary table **the same day**, while you still remember who was absent.
- จำนวนในแถว "ใช้วิเคราะห์ได้" คือจำนวน *n* ที่ต้องรายงานในรายงาน ห้ามรายงานเป็นอย่างอื่น
  The "complete both sets" count is the *n* to report. Report that number, not a rounder one.
