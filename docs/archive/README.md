# Archive — the superseded endless-runner prototype

The files in this folder describe **River Dash: Safe Feast Run**, an earlier 3D endless runner
built on the same Godot project. It taught liver fluke prevention through incidental pop-ups.

It was replaced by **Fluke Free Kitchen** (ครัวปลอดพยาธิ) because the runner format does not fit
the competition brief:

* its interactions were reflex interactions, not cooking interactions;
* health content arrived as pop-ups rather than as the thing being practised;
* a runner has no natural place for a required knowledge question, or for recording which
  learning activities a student completed.

The reasoning, the reuse/replace decisions and the baseline measurements are recorded in
`../PROJECT_AUDIT.md`. These documents are kept only so the project's history is traceable; **do
not cite them for the current game.**
