# บทที่ 1 บทนำ

## 1.1 ที่มาและความสำคัญของปัญหา

พยาธิใบไม้ตับ (*Opisthorchis viverrini*) เป็นพยาธิที่ระบาดมากในภาคตะวันออกเฉียงเหนือของประเทศไทย
คนได้รับเชื้อจากการรับประทานปลาน้ำจืดดิบหรือกึ่งสุกกึ่งดิบที่มีตัวอ่อนระยะติดต่อ (metacercariae)
ปะปนอยู่ เช่น ก้อยปลา ปลาส้ม และปลาร้าที่ไม่ได้ปรุงสุก เมื่อตัวอ่อนเข้าสู่ร่างกายจะเจริญในท่อน้ำดี
และก่อให้เกิดการอักเสบเรื้อรัง ซึ่งเป็นปัจจัยเสี่ยงสำคัญของมะเร็งท่อน้ำดี (cholangiocarcinoma)
โดยหน่วยงานมะเร็งขององค์การอนามัยโลก (IARC) จัดให้การติดเชื้อ *O. viverrini* เป็นสารก่อมะเร็งใน
มนุษย์กลุ่ม 1 (Group 1) [7], [8]

แม้ว่าโรคนี้จะป้องกันได้ด้วยวิธีที่ชัดเจนและมีหลักฐานรองรับ แต่ปัญหาที่พบคือ

1. **พฤติกรรมเสี่ยงยังคงอยู่** การรับประทานปลาน้ำจืดดิบเป็นวัฒนธรรมการกินที่สืบทอดกันมาในบางพื้นที่
2. **ความเชื่อที่คลาดเคลื่อน** หลายคนเชื่อว่าการบีบมะนาว ใส่พริก การดอง หรือการรับประทานคู่กับ
   เครื่องดื่มแอลกอฮอล์ สามารถฆ่าตัวอ่อนพยาธิได้ ซึ่งไม่เป็นความจริง งานศึกษาในกลุ่มผู้ที่มีความเสี่ยง
   ต่อมะเร็งท่อน้ำดีพบว่า ผู้ที่เชื่อเช่นนี้มีโอกาสติดเชื้อสูงกว่าอย่างมีนัยสำคัญ [10] และกรมควบคุมโรค
   ระบุชัดเจนว่าวิธีที่ปลอดภัยมีเพียงการปรุงให้สุกด้วยความร้อนเท่านั้น [6]
3. **ความรู้เรื่องการป้องกันยังไม่ถูกส่งต่ออย่างเป็นระบบ** โดยเฉพาะกับเด็กและเยาวชนที่อยู่ในพื้นที่เสี่ยง

การให้ความรู้เรื่องการป้องกันโรคพยาธิใบไม้ตับและมะเร็งท่อน้ำดีจึงเป็นมาตรการที่สำคัญ การสอนผ่าน
"เกม" เป็นช่องทางหนึ่งที่เข้าถึงเด็กได้ดี เพราะเปิดโอกาสให้ผู้เล่นได้ลงมือทำซ้ำ ตัดสินใจ และเห็นผลลัพธ์
ทันที มากกว่าการอ่านเอกสารเพียงอย่างเดียว อย่างไรก็ตาม เมื่อเกมเป็นสื่อการสอนด้านสุขภาพ จะต้อง
ระวังเป็นพิเศษว่าเนื้อหาที่ถ่ายทอดนั้น **ถูกต้องและตรวจสอบได้** ไม่สร้างความรู้สึกปลอดภัยที่ผิด
และไม่กล่าวอ้างผลลัพธ์การเรียนรู้ที่ยังไม่ได้วัดจริง

## 1.2 ปัญหาและช่องว่าง (problem statement)

เมื่อทบทวนสื่อและเกมเพื่อการสอนสุขภาพที่มีอยู่ พบช่องว่างที่โครงการนี้ตั้งใจปิด ดังนี้

1. **เกมทำอาหารหรือเกมจำลองครัวที่มีอยู่ทั่วไป** เน้นความสนุกและการแข่งขันเป็นหลัก เนื้อหา
   ด้านความปลอดภัยของอาหารมักเป็นเพียงส่วนประกอบ ไม่ได้ถ่ายทอดหลักวิทยาศาสตร์ด้วยความแม่นยำ
   และไม่ได้อ้างอิงแหล่งข้อมูลที่ตรวจสอบได้
2. **แอปแบบคำถาม–คำตอบ** ถ่ายทอด "ข้อเท็จจริง" ได้ดี แต่ไม่ได้ฝึก "การปฏิบัติ" เช่น การแยกเขียงดิบ
   และเขียงสุก การล้างมือ หรือการปรุงปลาให้สุกทั่วถึง
3. **สื่อส่วนใหญ่ไม่ได้แก้ความเชื่อที่คลาดเคลื่อนโดยตรง** ทั้งที่ความเชื่อเหล่านี้เป็นสาเหตุสำคัญของ
   พฤติกรรมเสี่ยง
4. **สื่อภาษาไทยที่สอดคล้องกับหลักสูตรและกลุ่มเป้าหมายนักเรียนไทยยังมีจำกัด** ทั้งที่กลุ่มเป้าหมาย
   อยู่ในพื้นที่ที่มีความชุกของโรคสูง

โครงการนี้จึงพัฒนาเกม 3 มิติเพื่อการศึกษาในชื่อ **"ครัวปลอดพยาธิ" (Fluke Free Kitchen)**
ที่ให้ผู้เล่นทำภารกิจครัว 3 ระดับ โดยเนื้อหาสุขภาพทุกประโยคอ้างอิงแหล่งข้อมูลที่ตรวจสอบแล้ว
และตัวเกมบังคับให้ผู้เล่นต้องตอบคำถามความรู้ให้ถูกก่อนจึงจะผ่านแต่ละด่าน

## 1.3 วัตถุประสงค์

1. พัฒนาเกมเพื่อการศึกษา "ครัวปลอดพยาธิ" ที่สอนเรื่องการป้องกันโรคพยาธิใบไม้ตับและมะเร็ง
   ท่อน้ำดี สำหรับนักเรียนระดับประถมศึกษา มัธยมศึกษาตอนต้น และมัธยมศึกษาตอนปลาย
2. ออกแบบภารกิจให้ผู้เล่นลงมือปฏิบัติจริง เพื่อแสดงพฤติกรรมป้องกันที่ทำได้จริงในครัวเรือน
3. ให้เกมแก้ **ความเชื่อที่คลาดเคลื่อน** โดยตรง ด้วยการจัดให้ความเชื่อเหล่านั้นเป็นส่วนหนึ่งของ
   เนื้อหาและคำถาม ไม่ใช่เพียงข้อความตอบกลับ
4. จัดทำเครื่องมือวัดความรู้และทัศนคติ (ข้อสอบก่อน–หลังเรียน) และแผนการวิเคราะห์ ที่จะใช้ประเมิน
   ผลการเรียนรู้ในขั้นต่อไป
5. ยืนยันความถูกต้องของเนื้อหาสุขภาพทุกข้อด้วยการอ้างอิงแหล่งข้อมูลที่เชื่อถือได้ และเปิดเผย
   ข้อจำกัดอย่างตรงไปตรงมา

## 1.5 ขอบเขตการศึกษา

* **เนื้อหา:** โรคพยาธิใบไม้ตับและมะเร็งท่อน้ำดีในบริบทของประเทศไทย ครอบคลุม 6 เรื่องที่ต้องแยก
  จากกัน ได้แก่ การติดเชื้อ ความปลอดภัยของอาหาร สุขาภิบาล การคัดกรอง การรักษา และมะเร็งท่อน้ำดี
* **กลุ่มเป้าหมาย:** นักเรียนไทยระดับประถมศึกษา มัธยมศึกษาตอนต้น และมัธยมศึกษาตอนปลาย
* **รูปแบบ:** เกม 2.5 มิติ (ฉาก 3 มิติ มุมกล้องคงที่ + ส่วนติดต่อผู้ใช้ 2 มิติ) ทำงานแบบออฟไลน์
  ใช้เมาส์หรือการสัมผัสหน้าจอโดยตรง ภาษาไทยและอังกฤษ
* **สิ่งที่อยู่นอกขอบเขต:** ไม่ใช่เกมวิ่งไม่สิ้นสุด ไม่มีด่านไม่มีที่สิ้นสุด ไม่มีโลกเปิด ไม่มีฟิสิกส์
  ซับซ้อน ไม่มีผู้เล่นหลายคน และไม่มีระบบไอเท็ม

## 1.6 นิยามศัพท์

* **พยาธิใบไม้ตับ** หมายถึง *Opisthorchis viverrini* พยาธิใบไม้ในตับที่พบมากในภูมิภาคนี้
* **ตัวอ่อนระยะติดต่อ (metacercariae)** ระยะของพยาธิที่อยู่ในกล้ามเนื้อปลาน้ำจืด และเป็นระยะที่
  ติดต่อสู่คนได้เมื่อรับประทานปลาที่ไม่สุก
* **มะเร็งท่อน้ำดี (cholangiocarcinoma)** มะเร็งที่เกิดจากเซลล์เยื่อบุท่อน้ำดี
* **ความเชื่อที่คลาดเคลื่อน (misconception)** ความเชื่อที่ขัดกับหลักฐาน เช่น การเชื่อว่ามะนาวหรือ
  แอลกอฮอล์ฆ่าพยาธิได้
* **ผลการเรียนรู้** ในรายงานนี้หมายถึงความรู้และเจตนาเชิงพฤติกรรมของนักเรียน ซึ่ง **ยังไม่ได้วัด**
  ในการศึกษาครั้งนี้ (ดูบทที่ 4)

## 1.7 ประโยชน์ที่คาดว่าจะได้รับ

1. ได้สื่อการเรียนรู้ภาษาไทยที่เนื้อหาด้านสุขภาพผ่านการตรวจสอบแหล่งอ้างอิงทุกข้อ
2. ได้ต้นแบบเกมเพื่อการศึกษาแบบ 2.5 มิติที่บังคับให้ผู้เรียนผ่านการตรวจความรู้ก่อนจบด่าน
3. ได้เครื่องมือวัดก่อน–หลังเรียนและแผนการวิเคราะห์ทางสถิติที่พร้อมใช้เก็บข้อมูลจริง
4. ได้แนวทางสำหรับครูและบุคลากรสาธารณสุขในการนำไปใช้ในชั้นเรียนหรือกิจกรรมชุมชน
5. ได้ข้อเสนอเชิงระเบียบวิธีสำหรับงานวิจัยเชิงทดลองในชั้นเรียนในอนาคต
