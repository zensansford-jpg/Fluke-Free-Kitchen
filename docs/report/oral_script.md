# สคริปต์นำเสนอปากเปล่า (Oral presentation)

> **ข้อกำหนด:** นำเสนอ **ไม่เกิน 5 นาที** ตามด้วย **ถาม–ตอบ ไม่เกิน 10 นาที** ·
> **ภาษาไทย** เป็นหลัก (เตรียมศัพท์อังกฤษเท่าที่จำเป็น) ·
> **ห้ามพูดถึงผลลัพธ์ที่ยังไม่ได้วัด** เช่น เปอร์เซ็นต์การพัฒนาความรู้ จำนวนผู้เข้าร่วม
> หรือข้อสรุปว่า "เด็กเข้าใจดีขึ้น" เพราะโครงการนี้ยังไม่ได้เก็บข้อมูลและยังไม่ผ่านจริยธรรม
>
> เอกสารนี้เป็น **โครงและตัวอย่างคำพูด** ปรับให้เป็นภาษาของทีมได้ แต่ต้องคงข้อเท็จจริงและ
> ข้อจำกัดไว้ **ห้ามตัดข้อจำกัดออกเพื่อให้ดูดีขึ้น**

**ผู้พูด:** นักเรียนในทีม 1–3 คน แบ่งช่วงกันพูดได้ · **อุปกรณ์สาธิต:** เครื่องที่เปิดเกมได้จริง
(ถ้าเปิดสาธิตสดไม่ได้ ให้เตรียมภาพ/วิดีโอที่บันทึกจากการเล่นจริง ไม่ใช่ภาพจำลอง)

## สคริปต์คำพูด (ตัวอย่าง)

**[ช่วง 1 — ปัญหา]** "ในภาคอีสาน ปลาน้ำจืดดิบอย่างก้อยปลาและปลาส้มเป็นอาหารที่คุ้นเคย แต่ตัวอ่อน
พยาธิใบไม้ตับในปลาเหล่านั้นเมื่อเข้าสู่ร่างกายจะเจริญในท่อน้ำดี และการติดเชื้อเรื้อรังเป็นปัจจัย
เสี่ยงสำคัญของมะเร็งท่อน้ำดี (IARC จัดเป็นกลุ่ม 1) โรคนี้ **ป้องกันได้** ด้วยการปรุงให้สุกและ
สุขอนามัยที่ถูกต้อง"

**[ช่วง 2 — ทางออก]** "คำถามของเราคือ ถ้าเด็กได้ *ลงมือทำ* ในครัวจำลอง แทนที่จะแค่อ่าน จะเข้าใจ
และจดจำได้ดีขึ้นไหม เราจึงสร้าง 'ครัวปลอดพยาธิ' เกมปรุงอาหารที่ **ผ่านด่านไม่ได้ถ้ายังตอบคำถาม
ความรู้ผิด** การศึกษาไม่ใช่ส่วนเสริมแต่เป็นเงื่อนไขของเกม"

**[ช่วง 3 — สาธิต]** (บรรยายขณะเล่น) "เริ่มจากล้างมือครับ … แยกเขียงดิบออกจากเขียงสุก … แล้วปรุง
ปลาให้สุกทั่วถึงด้วยความร้อน … สังเกตว่าต้องตอบคำถามให้ถูกก่อนจึงจะผ่านด่าน … ถ้าเราเลือกเสิร์ฟ
ปลาที่ยังสุกไม่พอ เกมจะหยุดและอธิบายว่า ผู้ที่รับประทานจะ *สัมผัส* ตัวอ่อน ซึ่งเป็นความเสี่ยงที่
จะติดเชื้อ ไม่ใช่การติดเชื้อที่เกิดขึ้นแล้ว และไม่เท่ากับมะเร็ง … ถ้าปรุงนานเกินไปปลาจะไหม้ และ
เริ่มใหม่ได้ทันที"

**[ช่วง 4 — ความน่าเชื่อถือ]** "ทุกข้อความสุขภาพในเกมอ้างอิงแหล่งข้อมูลที่ตรวจสอบได้ ทั้ง WHO,
CDC, IARC และงานวิจัย รวม 11 แหล่งที่เราตรวจสอบด้วยมือแล้ว และระบบจะตรวจสอบแหล่งอ้างอิงทุกครั้ง
ที่เริ่มโปรแกรม เราจงใจย้ำว่า **สีเหลืองทองเพียงอย่างเดียวไม่ใช่หลักประกันว่าปลอดภัย** ความ
ปลอดภัยตัดสินจากอุณหภูมิภายในและระยะเวลาที่คงไว้ ไม่ใช่จากสี"

**[ช่วง 5 — การทดสอบ]** "เราทดสอบเกมด้วยชุดทดสอบอัตโนมัติ 8 ชุด ครอบคลุมพื้นที่หน้าจอ 12 ขนาด
(รวม 360 เค้าโครง) และส่งออกให้ทำงานได้บน Windows, เว็บ และ Android ครับ"

**[ช่วง 6 — ความซื่อสัตย์]** "เราขอพูดตรง ๆ ว่า เรา *ยังไม่ได้วัดผลการเรียนรู้กับนักเรียน* เพราะ
ต้องขออนุมัติด้านจริยธรรมก่อน สิ่งที่เรามีตอนนี้คือเกมที่ทดสอบแล้ว เนื้อหาที่ตรวจสอบแล้ว และ
เครื่องมือวัดที่พร้อมใช้ ก้าวต่อไปของเราคือการเก็บข้อมูลจริงและรายงานผลตามจริง"

## เตรียมตอบคำถาม (Q&A 10 นาที)

ตอบสั้น ตรง และ **ไม่เดา** ถ้าไม่รู้ ให้บอกว่าไม่รู้และจะไปตรวจสอบ คำตอบที่เป็น "เรายังไม่ได้ทำ"
ปลอดภัยกว่าการเดาเสมอ

| คำถามที่คาดว่าจะถูกถาม | แนวคำตอบที่ถูกต้อง |
|------------------------|--------------------|
| "ผลการเรียนรู้เป็นอย่างไรบ้าง" | ยังไม่ได้เก็บข้อมูล เพราะยังไม่ได้รับการอนุมัติด้านจริยธรรม สิ่งที่พร้อมแล้วคือข้อสอบก่อน–หลัง 6+6 ข้อ แบบสอบถาม และเครื่องมือวิเคราะห์ที่ผ่านการตรวจสอบสูตร (`--selftest`) |
| "ทำไมไม่เก็บข้อมูลเลย" | ประกาศการแข่งขันกำหนดให้ต้องได้ความเห็นชอบด้านจริยธรรมและความยินยอม **ก่อน** และไม่อนุมัติย้อนหลัง จึงยังไม่เริ่มเก็บ |
| "ทำไมแยกสีของอาหารออกจากความปลอดภัย" | เพราะสีเหลืองทองอาจทำให้ "มั่นใจผิด"; เราจึงแยกภาพการสุก (เพื่อความสวยงาม) ออกจากตรรกะความปลอดภัย (อุณหภูมิภายใน + เวลา) |
| "อุณหภูมิปลอดภัยคือเท่าไร" | อ้างเกณฑ์ของ CDC ที่ 145 °F (~63 °C) ภายใน; เรา **ไม่ประดิษฐ์เกณฑ์สากล** และรายงานผลการทดลอง (ต้ม/ไมโครเวฟ ≥ 5 นาที, แช่แข็ง −20 °C ≥ 48 ชั่วโมง) ตามที่ทดลองจริง |
| "เชื่อได้อย่างไรว่าเนื้อหาถูก" | เนื้อหาอยู่ในฐานข้อมูลแยกจากโค้ด มีบัญชีแหล่งอ้างอิงที่อนุญาต และระบบจะปฏิเสธหากอ้างแหล่งที่ไม่อนุญาต; เราตรวจมือทั้ง 11 แหล่งและแก้ URL ที่ผิด |
| "ทำไมต้องบังคับตอบคำถามก่อนผ่านด่าน" | เพื่อให้การศึกษาเป็นเงื่อนไขของเกม ไม่ใช่ส่วนเสริม และเพื่อไม่ให้ได้ดาวโดยไม่เข้าใจ |
| "เด็กที่อ่านไม่ออกจะเล่นได้ไหม" | ทุกท่ามีการสาธิตก่อนลงมือ และข้อความมีสองระดับ (ง่าย/ละเอียด); ใช้เมาส์หรือการสัมผัสหน้าจอ ไม่ต้องใช้คีย์บอร์ด |
| "เก็บข้อมูลส่วนตัวของผู้เล่นหรือไม่" | เกมทำงานออฟไลน์ ไม่ขอสิทธิ์ใด ๆ และไฟล์ส่งออก **ไม่ระบุตัวตน** (ไม่มีชื่อ/รหัส/รุ่นเครื่อง) ส่วนข้อมูลส่วนบุคคลถ้าจำเป็นให้เก็บนอกเกมและทำลายเมื่อเสร็จ |
| "ทดสอบบนมือถือจริงหรือยัง" | ยังครับ ไม่มีอุปกรณ์/โปรแกรมจำลองในสภาพแวดล้อมที่พัฒนา ไฟล์ APK ผ่านการตรวจสอบเชิงโครงสร้าง (ลายเซ็น, สิทธิ์, ABI) เท่านั้น และเราระบุตรงไปตรงมา |
| "อะไรใหม่เมื่อเทียบกับเกมสุขภาพทั่วไป" | (1) บังคับความรู้ก่อนผ่านด่าน (2) ความเชื่อที่คลาดเคลื่อนถูกจัดเป็นข้อมูลที่มีบทเรียนรองรับ (3) แยกภาพสุกออกจากความปลอดภัย (4) เนื้อหาตรวจสอบได้ด้วยเครื่อง |
| "ทดสอบอะไรบ้าง" | 8 ชุด: smoke, anim, flow, behaviour, cook, recipe, minigame, responsive — และเก็บภาพหน้าจอเพื่อตรวจด้วยสายตา |
| "ใช้ต้นทุนเท่าไร" | ไม่ใช้ซอฟต์แวร์หรือปลั๊กอินที่มีค่าใช้จ่าย (Godot, ฟอนต์ Sarabun แบบ OFL, Python) |

## ห้ามพูด (เพื่อความซื่อสัตย์และตามเกณฑ์การให้คะแนน)

* ห้ามบอกตัวเลขเปอร์เซ็นต์การพัฒนาความรู้หรือจำนวนผู้เข้าร่วม
* ห้ามสรุปว่าเกม "ได้ผล" หรือ "เปลี่ยนพฤติกรรม" — ยังไม่มีข้อมูล
* ห้ามอ้างว่าเนื้อหาผ่านการรับรองจากแพทย์/หน่วยงาน ถ้าเพียงตรวจเทียบกับแหล่งอ้างอิง
* ห้ามอ้างว่าทดสอบบนอุปกรณ์ Android จริงแล้ว (ตรวจได้เพียงเชิงโครงสร้าง)
