# บันทึกการทำงาน (Logbook)

> **วิธีใช้ไฟล์นี้.** การแข่งขันให้คะแนน "บันทึกการทำงาน ความซื่อสัตย์ จริยธรรม และความปลอดภัย"
> บันทึกนี้ต้อง **เริ่มตั้งแต่วันแรกของการทำงาน และบันทึกเฉพาะสิ่งที่เป็นจริง** ห้ามเติมย้อนหลัง
> ด้วยสิ่งที่ไม่ได้เกิดขึ้น สำหรับงานที่ทำไปแล้วและไม่มีบันทึกเวลา ให้ใส่ **ช่วงเวลาโดยประมาณ**
> และกำกับด้วยคำว่า "(ประมาณ)" อย่างชัดเจน
>
> โครงสร้างนี้จัดทำขึ้นเพื่อให้ทีมเริ่มบันทึกได้ทันที ส่วนตารางด้านล่างบันทึกเฉพาะงานที่ **ทราบ
> วันเวลาแน่นอน** เท่านั้น ช่องที่เหลือให้ทีมเติมจากบันทึกจริงของตน

## 3. จริยธรรมและความปลอดภัย (ต้องบันทึกก่อนเก็บข้อมูล)

รายการเหล่านี้ต้องมีหลักฐานเป็นลายลักษณ์อักษรในบันทึก **ก่อน** เริ่มเก็บข้อมูลใด ๆ
(ตามที่ระบุใน `docs/RESEARCH_PLAN.md` หัวข้อ 4)

- [ ] ได้รับอนุญาตจากผู้บริหารโรงเรียน (วันที่: [[ วันที่ ]], เอกสาร: [[ อ้างอิง ]])
- [ ] ยื่นและได้รับความเห็นชอบจากคณะกรรมการจริยธรรม (วันที่ยื่น: [[ ]]; วันที่อนุมัติ: [[ ]])
- [ ] เอกสารข้อมูลสำหรับผู้ปกครองพร้อมแล้ว
- [ ] แบบฟอร์มความยินยอมผู้ปกครองพร้อมแล้ว
- [ ] แบบฟอร์มความยินยอมของนักเรียน (assent) พร้อมแล้ว
- [ ] แนวทางคุ้มครองข้อมูลและกำหนดวันทำลายข้อมูลชัดเจน

> สถานะปัจจุบัน: **ยังไม่ได้ดำเนินการข้อใด** จึงยังไม่มีการเก็บข้อมูล

## 4. ปัญหาและวิธีแก้ (ตัวอย่างที่เกิดขึ้นจริง)

| ปัญหา | วิธีแก้ |
|-------|--------|
| URL ของหน้าอ้างอิง CDC บางหน้าไม่ถูกต้อง | เปิดหน้าเว็บจริงและแก้ URL ให้ถูกต้อง |

## 5. ข้อเสนอแนะสำหรับทีม

1. บันทึกทุกครั้งที่ทำงาน ระบุวันที่ กิจกรรม และสิ่งที่ได้จริง
2. เก็บภาพหน้าจอและไฟล์ผลลัพธ์เป็นหลักฐาน
3. อย่าลบรายการที่ผิดพลาดออก ให้บันทึกไว้เป็นส่วนหนึ่งของกระบวนการ
4. ก่อนส่ง ให้ตรวจว่าไม่มีรายการใดที่ยังเป็น "(ประมาณ)" หรือ [[ ]]
