# บทคัดย่อ · ข้อเสนอโครงการ · บทสรุปผู้บริหาร

## 1. บทคัดย่อ (Abstract)

โรคพยาธิใบไม้ตับ (*Opisthorchis viverrini*) เป็นปัญหาสาธารณสุขสำคัญของภาคตะวันออกเฉียงเหนือ
ของประเทศไทย การติดเชื้อเกิดจากการรับประทานปลาน้ำจืดดิบหรือกึ่งสุกกึ่งดิบ และการติดเชื้อเรื้อรัง
เป็นปัจจัยเสี่ยงสำคัญของมะเร็งท่อน้ำดี โดย IARC จัดให้การติดเชื้อนี้เป็นสารก่อมะเร็งในมนุษย์กลุ่ม 1
แม้โรคจะป้องกันได้ แต่ความเชื่อที่คลาดเคลื่อน เช่น การเชื่อว่ามะนาว การดอง หรือแอลกอฮอล์ฆ่าพยาธิ
ได้ ยังคงทำให้เกิดพฤติกรรมเสี่ยง โครงการนี้จึงพัฒนาเกมเพื่อการศึกษา "ครัวปลอดพยาธิ"
(Fluke Free Kitchen) ซึ่งเป็นเกม 2.5 มิติ ภาษาไทยและอังกฤษ ประกอบด้วยภารกิจเนื้อเรื่อง 3 ระดับ
และโหมดเสริมอีกหลายแบบที่ใช้กลไกทำอาหารเดียวกัน
ครอบคลุม 13 บทเรียน และบังคับให้ผู้เล่นต้องตอบคำถามความรู้ให้ถูกก่อนผ่านด่าน

เกมพัฒนาด้วย Godot 4.7.2 และผ่านการทดสอบอัตโนมัติ 8 ชุด รวมถึงการทดสอบเค้าโครง UI
360 เค้าโครงจาก 12 ขนาดหน้าจอ เนื้อหาสุขภาพทุกประโยคอ้างอิงแหล่งข้อมูลที่เชื่อถือได้ และ
แหล่งอ้างอิงทั้ง 11 แหล่งผ่านการตรวจสอบด้วยมือแล้ว เกมส่งออกและทำงานได้บน Windows, Web และ
Android (iOS ติดข้อจำกัดด้านเครื่องมือ) โครงการยังได้จัดเตรียมข้อสอบก่อน–หลังเรียน 6 + 6 ข้อ
และเครื่องมือวิเคราะห์ทางสถิติที่ผ่านการตรวจสอบสูตรแล้ว **อย่างไรก็ดี โครงการนี้ยังไม่ได้เก็บข้อมูล
การเรียนรู้กับนักเรียน เนื่องจากยังไม่ได้รับการอนุมัติด้านจริยธรรม** จึงยังไม่มีการรายงานผลการเรียนรู้
หรือพฤติกรรมใด ๆ และตัวเกมเองก็แจ้งข้อจำกัดนี้กับผู้ใช้อย่างตรงไปตรงมา

**คำสำคัญ:** พยาธิใบไม้ตับ, มะเร็งท่อน้ำดี, เกมเพื่อการศึกษา, ความเชื่อที่คลาดเคลื่อน,
การป้องกันโรค

## 2. ข้อเสนอโครงการ (Proposal)

### 2.1 หลักการและเหตุผล

การป้องกันโรคพยาธิใบไม้ตับและมะเร็งท่อน้ำดีอาศัยการปรับพฤติกรรม (ปรุงปลาให้สุก แยกดิบ–สุก
รักษาสุขาภิบาล) ซึ่งต้องเริ่มจากความเข้าใจที่ถูกต้องตั้งแต่วัยเรียน สื่อการสอนที่ทำให้ผู้เรียนได้ลงมือ
ปฏิบัติและแก้ความเชื่อที่คลาดเคลื่อนโดยตรงจึงมีคุณค่า เกมเป็นสื่อที่ทำได้ทั้งสองอย่างพร้อมกัน แต่
ต้องระวังไม่ให้เกิดความเชื่อมั่นที่ผิด (เช่น เข้าใจว่าสีเหลืองทองคือความปลอดภัย)

### 2.2 วัตถุประสงค์

1. พัฒนาเกมเพื่อการศึกษาเรื่องการป้องกันโรคพยาธิใบไม้ตับและมะเร็งท่อน้ำดี สำหรับนักเรียน 3 ระดับ
2. ให้เกมแก้ความเชื่อที่คลาดเคลื่อนโดยตรง และบังคับให้เกิดการตรวจความรู้ก่อนผ่านด่าน
3. จัดทำเครื่องมือวัดความรู้ (ก่อน–หลังเรียน) และแผนการวิเคราะห์ผล
4. ยืนยันความถูกต้องของเนื้อหาสุขภาพด้วยแหล่งอ้างอิงที่ตรวจสอบได้

### 2.3 วิธีดำเนินการ (สรุป)

* **พัฒนาเกม** ด้วย Godot 4.7.2 (ฉาก 3 มิติ มุมกล้องคงที่ + UI 2 มิติ)
* **ตรวจสอบเนื้อหา** ด้วยบัญชีแหล่งอ้างอิงที่อนุญาตและระบบตรวจสอบอัตโนมัติ
* **ทดสอบ** ด้วยชุดทดสอบอัตโนมัติ 8 ชุด และการทดสอบขนาดหน้าจอ 12 ขนาด (รวม 360 เค้าโครง)
* **ส่งออก** เป็น Windows, Web และ Android
* **ประเมินผล (planned)** ด้วยแบบแผนก่อน–หลังเรียนกลุ่มเดียว (และกลุ่มเปรียบเทียบถ้าจัดได้)
  โดยขออนุมัติด้านจริยธรรมและความยินยอมให้ครบก่อนเก็บข้อมูล

### 2.4 ผลผลิตและผลลัพธ์ที่คาดหวัง

* **ผลผลิต:** เกม "ครัวปลอดพยาธิ" ที่ทำงานได้จริง + เอกสารเนื้อหาและเครื่องมือวัดที่ตรวจสอบได้
* **ผลลัพธ์ที่คาดหวัง (ยังไม่ยืนยัน):** ความรู้ที่เพิ่มขึ้นและความเชื่อที่คลาดเคลื่อนลดลงในนักเรียน
  ซึ่งจะยืนยันได้หลังการเก็บข้อมูลจริงเท่านั้น

### 2.5 ทรัพยากรและงบประมาณ

ไม่ใช้ทรัพย์สินหรือปลั๊กอินที่มีค่าใช้จ่าย ทั้งซอฟต์แวร์สำหรับพัฒนา ฟอนต์ และเครื่องมือวิเคราะห์
เป็นของฟรีทั้งหมด (Godot Engine, ฟอนต์ Sarabun, Python) จึงใช้งบประมาณเฉพาะวัสดุจัดทำบอร์ด
และค่าใช้จ่ายในการเดินทางไปเก็บข้อมูล (ตามที่โรงเรียนกำหนด)

### 2.6 ระยะเวลา

สอดคล้องกับกรอบเวลา 12 เดือนก่อนการสมัคร โดยการดำเนินการหลัก (พัฒนาและทดสอบ) เสร็จแล้ว
และขั้นตอนที่เหลือคือการขออนุมัติด้านจริยธรรม การเก็บข้อมูล และการจัดทำวีดิทัศน์และบอร์ด

## 3. บทสรุปผู้บริหาร (Project Summary)

**ครัวปลอดพยาธิ** คือเกมเพื่อการศึกษา 2.5 มิติ ที่สอนการป้องกันโรคพยาธิใบไม้ตับและมะเร็ง
ท่อน้ำดีผ่านภารกิจครัว 3 ระดับ มีจุดเด่น 4 ประการ ได้แก่ (1) การศึกษาเป็นเงื่อนไขของการผ่านด่าน
ไม่ใช่ส่วนเสริม (2) ความเชื่อที่คลาดเคลื่อนถูกจัดการโดยตรง (3) เนื้อหาสุขภาพตรวจสอบได้ด้วยเครื่อง
และ (4) แยก "ภาพการสุก" ออกจาก "ความปลอดภัย" อย่างชัดเจนเพื่อไม่ให้ผู้เรียนมั่นใจผิด

ผลิตภัณฑ์เสร็จและทดสอบแล้ว ทั้งบนเดสก์ท็อป เว็บ และ Android โดยมีเนื้อหาอ้างอิงแหล่งที่เชื่อถือได้
11 แหล่งที่ผ่านการตรวจสอบแล้ว โครงการได้จัดเตรียมเครื่องมือวัดการเรียนรู้และแผนการวิเคราะห์
ทางสถิติไว้พร้อมใช้ จุดที่ยังต้องทำคือ **การเก็บข้อมูลการเรียนรู้จริงกับนักเรียน** ซึ่งจำเป็นต้องได้รับ
การอนุมัติด้านจริยธรรมและความยินยอมก่อน โครงการจึงเลือกที่จะ **ไม่กล่าวอ้างผลลัพธ์ที่ยังไม่ได้วัด**
และรายงานข้อจำกัดนี้อย่างโปร่งใสทั้งในเกม ในรายงาน และในบทสรุปนี้
