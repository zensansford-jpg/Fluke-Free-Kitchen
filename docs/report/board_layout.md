# แผนบอร์ดแสดงผล (Display Board)

> **วัสดุที่ผู้จัดเตรียมให้:** บอร์ดโฟม ขนาด 150 ซม. ประกอบด้วยชิ้นส่วน 2× ก1 (60×60 ซม.)
> และชิ้นแบน 120×60 ซม. ให้ยึดชิ้นส่วนตามคำแนะนำของผู้จัดและวางเนื้อหาให้อ่านได้จากระยะไกล

**หลักการออกแบบ:** อ่านเข้าใจได้ใน 30 วินาที · ตัวอักษรใหญ่พออ่านจาก 1.5 เมตร ·
**ไม่แสดงผลลัพธ์ที่ยังไม่ได้วัด** · มีรหัส QR ไปยังวีดิทัศน์และ/หรือตัวเกม

## 2. ข้อความหลักบนบอร์ด (กระชับ)

**ชื่อเรื่อง:** ครัวปลอดพยาธิ — เกมปรุงอาหารเพื่อป้องกันมะเร็งท่อน้ำดี

**ข้อความ 1 (ปัญหา):** "ปลาน้ำจืดดิบ … ตัวอ่อนพยาธิใบไม้ตับ … การติดเชื้อเรื้อรังเป็นปัจจัยเสี่ยง
สำคัญของมะเร็งท่อน้ำดี (IARC กลุ่ม 1)"

**ข้อความ 2 (จุดเด่น):** "เกมบังคับให้ผู้เล่น *ตอบคำถามให้ถูกก่อนผ่านด่าน* และแก้ความเชื่อที่
คลาดเคลื่อน เช่น 'มะนาวหรือเหล้าฆ่าพยาธิได้' ซึ่งไม่จริง"

**ข้อความ 3 (ความน่าเชื่อถือ):** "เนื้อหาสุขภาพทุกข้ออ้างอิง 11 แหล่งที่ตรวจสอบแล้ว
(WHO, CDC, IARC, งานวิจัย) และเกมแยก 'ภาพการสุก' ออกจาก 'ความปลอดภัย' ชัดเจน"

**ข้อความ 4 (ความซื่อสัตย์):** "ยังไม่มีการวัดผลการเรียนรู้กับนักเรียน — สิ่งที่รายงานคือผลการ
ทดสอบซอฟต์แวร์และความถูกต้องของเนื้อหา ไม่ใช่ผลการเรียนรู้"

## 3. สิ่งที่ต้องเตรียมพร้อมกับบอร์ด

* **โมเดล/อุปกรณ์ประกอบ:** จอหรือแท็บเล็ตสาธิตเกม (ถ้ามี) หรือภาพหน้าจอขนาดใหญ่
* **รหัส QR:** อย่างน้อย 1 รหัส ไปยังวีดิทัศน์ (และตัวเกมหากเผยแพร่ได้)
* **สมุดความรู้/ไฟล์ตัวอย่าง:** เกม (Windows/Android), เอกสารเนื้อหา, เครื่องมือวิเคราะห์
* **ข้อมูลติดต่อทีม:** ชื่อโรงเรียนและสมาชิก

## 4. เช็กลิสต์ก่อนติดตั้งบอร์ด

- [ ] ตัวอักษรอ่านได้จากระยะ 1.5 เมตร (หัวข้อ ≥ 60 pt, เนื้อหา ≥ 28 pt โดยประมาณ)
- [ ] **ไม่มี** ตัวเลขผลลัพธ์การเรียนรู้หรือเปอร์เซ็นต์การพัฒนา
- [ ] ตัวเลขผลการทดสอบเป็นค่าจริง (8 ชุดทดสอบ, 360/360, ขนาดไฟล์จริง)
- [ ] ระบุชัดว่า iOS ยังไม่ได้ทดสอบ และ Android ยังไม่ทดสอบบนเครื่องจริง
- [ ] รหัส QR ใช้งานได้จริง (ทดสอบสแกน)
- [ ] ภาพหน้าจอเป็นภาพจากการเล่นจริง
- [ ] มีช่องว่าง/โต๊ะสำหรับสาธิตเกม
